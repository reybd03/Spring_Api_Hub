# Agent OS

This project uses **Agent OS v3** for standards and spec shaping.

- Standards: `agent-os/standards/` (index: `agent-os/standards/index.yml`)
- Product docs (when created): `agent-os/product/`
- Commands available in OpenCode: `/discover-standards`, `/inject-standards`, `/index-standards`, `/plan-product`, `/shape-spec`

When implementing work, consult relevant standards in `agent-os/standards/` before editing code. Prefer updating standards via `/discover-standards` rather than ad-hoc documentation.
