### Phase 3: Automation Domain Decomposition (api-ouw.3, 5/7 complete)

- **automation-service**: New dedicated service with database-per-service pattern
  - Port 8080, MySQL database (`automation_db`), base-path `/api/v1`
  - Entities: `AutomationEntity` (JPA, all original fields preserved)
  - Repository: `AutomationRepository` with custom duplicate deletion query
  - Services: `AutomationService` (CRUD, metrics, SSE), `AutomationActions` (PID/Docker),
    `Jenkins` (discovery, config, WebClient), `JenkinsDiscovery`, `JenkinsExecutorService`
  - Controllers: `AutomationController` (CRUD), `JenkinsController` (config/actions/discovery),
    `JenkinsSseController` (sys-stats/config SSE at 1s interval)
  - WebClientConfig for external Jenkins API calls
